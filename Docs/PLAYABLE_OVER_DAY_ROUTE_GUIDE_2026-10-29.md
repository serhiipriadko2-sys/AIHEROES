# AIHEROES — исправление подсказки для маршрутов длиннее дня

Дата: 29 октября 2026. Статус: **SOURCE_IMPLEMENTED / PORTABLE_CORE_PASS / UNREAL_BUILD_AND_GAMEPLAY_PENDING**.

## Почему это влияет на реальную играбельность

В основной кампании бюджет движения восстанавливается до 4 ходов на новый день. Ранее `FAIHeroesCampaignGuide::Build` для любого доступного, но слишком длинного выбранного маршрута со статусом `NeedsMoreMoves` советовал «закончите день».

Если суммарная цена пути **5 ходов**, ожидание нового дня само по себе не делает этот путь законным: максимум снова 4. Игрок мог безрезультатно повторять конец дня. Этот экранный дефект затруднял завершение одной основной партии, хотя базовый роутер правильно отказывал в исполнении.

## Теперь — два разных случая

| Известный маршрут | Совет игроку | Право на перемещение |
|---|---|---|
| Цена 3, осталось 2 | Закончить день, повторить подтверждение | Никакого автоматического движения |
| Цена 5, полный лимит 4 | Выбрать промежуточную свою открытую точку, затем подтвердить переход | Только новая выбранная игроком цель |
| Цена 5, в известном пути нет подходящей собственной точки | Короткая общая подсказка найти свою точку по дороге | Без выдумывания скрытого узла |
| Маршрут заблокирован охраной / неизвестен | Остаётся исходный отказ, нет приказа | Без обхода защит |

Для Road V2 рассмотрен реальный пятиузловой случай **ORE → HQ → FOREST → OUTPOST** стоимостью 5, когда RUINS охраняются. В этом сценарии HQ принадлежит игроку, уже открыт и достижим за 2 хода. Поэтому короткая подсказка «Через Цитадель Искры» корректна. Если нет подтверждённой собственной точки, конкретное имя не раскрывается.

## Код и ограничения

Изменения точечные, совместимые с существующим алгоритмом и UI:

- `Source/AIHeroes/Public/AIHeroesCampaignGuide.h`: в *read-only* контекст добавлены `FullDayMoveBudget`, `RouteTotalCost`, `IntermediateOwnedSite`. Контекст не сериализуется в SaveGame.
- `Source/AIHeroes/Private/AIHeroesCampaignGuide.cpp`: отдельная ветка для `RouteTotalCost > FullDayMoveBudget`; короткая строка «Через [своя локация]» для верхней полосы целей. Сохранились случаи армии без бойцов, движения в процессе, тумана войны, невыбранной цели, обычного завершения дня и победы.
- `Source/AIHeroes/Private/AIHeroesExplorerHUD.cpp`: связь с реальным `GetSelectedTravelPath`. Промежуточный пункт берётся только из `Path.Nodes`, при `bOwned`, `!IsHidden`, `IsNodeDiscovered` и Road V2. Никаких действий в мире не выполняется. Главная кнопка остаётся **disabled**, пока новый путь не выбран и не разрешён штатными правилами.
- `Source/AIHeroes/Private/Tests/AIHeroesPlayableJourneyTests.cpp`: тест `AIHeroes.PlayableJourney.OverDayRouteNeedsWaypoint` на обе ветки и неизвестный промежуточный пункт.
- `Source/AIHeroes/Private/Tests/AIHeroesTravelIntegrationTests.cpp`: тест `AIHeroes.TravelV2.OverDayPathHasReachableOwnedStop` с настоящей дорожной схемой, ценой 5, достижимыми HQ/FOREST и отсутствием расходов/взятия чужой точки.

**Не изменялись:** 4 хода/день, стоимость дорог, охрана, здоровье, алгоритм боя, правила авторизации похода, SaveGame, дневной доход, покупка протоколов, формат JSON и основная игровая кампания.

### Что НЕ проверено

- Unreal Editor/Game текущего дерева **не компилировались в этом проходе**: в предыдущих двух попытках возникли Windows/MSVC ошибки из-за давления на виртуальную память. Менять системный файл подкачки и закрывать пользовательские процессы без согласия не стали.
- Новые Unreal Automation `OverDayRouteNeedsWaypoint` и `OverDayPathHasReachableOwnedStop` **написаны, но ещё не запущены**.
- Настоящий GPU HUD, клики по предложенной остановке, бои и полное прохождение основной кампании **не проверялись** на новой DLL.
- Выбор остановки остаётся **человеческим действием**. Это не автоматическое дробление маршрута на несколько ходов, не новый Pathfinder и не гарантия, что каждый возможный исходный мир имеет удобный пункт.
