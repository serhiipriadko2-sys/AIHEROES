# AIHEROES — русскоязычная панель базы (первый игровой цикл)

Дата локального прохода: 2026-10-29.
Режим: самостоятельная минимальная правка presentation-only в основной пятиузловой кампании.
Статус: **SOURCE_WRITTEN_STATIC_CHECK_PASS / UNREAL_BUILD_NOT_RUN**.

## Задача

При открытии «Построек [G]» игрок должен понять, какие здания,
отряды и протоколы он выбирает, сколько это стоит, почему покупка
в данный момент запрещена и как подтвердить действие.
Старые надписи BASE MANAGEMENT, AVAILABLE, CONFIRM и MODEL SLOT
заменены на понятные русскоязычные тексты в игровом интерфейсе.

## Реализовано

- Новый `FAIHeroesBasePanelCopy`: отображает пять типов покупок,
  их стоимость, краткие свойства, доступность и причину блокировки.
- Для модели 3B/8B отдельно показано, что это тематический слот,
  а не установленные нейросетевые веса.
- Локализованы известные исходы выбора, отказа и подтверждения покупки.
  Неизвестные события остаются без изменений: отображение не скрывает
  сообщения движка и не выдумывает причину сбоя.
- Для узкой панели (менее 760 px) используется краткая информационная строка.
  Прежние клавиши U/1/2/P/M, Enter, Esc, G остаются без изменений.
- `AIHeroes.UI.BasePanelCopy.OfferStates` проверяет пять предложений,
  их названия, цену, состояние и границы уровней.
- `AIHeroes.UI.BasePanelCopy.SafetyAndMessages` проверяет причину
  нехватки ресурсов, ошибочные данные, неизменность цены и сообщения.
- При показе остатка после покупки UI теперь **не пересчитывает** ресурсы
  заново: отображает цифры из подтверждённого расчёта игрового GameMode.
  Это устраняет риск расхождения экранной суммы и фактической заявки.
- В открытом VS Code добавлена задача
  `AIHEROES: Check Russian base UI (read-only)` для безопасной
  самостоятельной проверки без запуска Unreal и изменений сохранений.

## Границы

Код `AIHeroesBasePanelRules`, `AIHeroesGameMode`, расчёт ресурсов,
состав армии, боевые правила, SaveGame и обработчики действий не менялись.
Подтверждение покупки остаётся у GameMode и проверяет актуальность заявки.
Изменён только способ отображения уже проверенных полей.

Полная международная локализация ещё не выполнена: текущая Canvas-реализация
использует FString. Долгосрочный путь Unreal Engine — FText с LOCTEXT и
строковыми таблицами. Этот этап закрывает русскоязычный UX прототипа,
не заявляя готовность для других языков.

## Как наблюдать и проверять работу прямо в VS Code

Открыт существующий workspace `AIHEROES`; новые C++-файлы и
тесты доступны в проводнике проекта. Для самопроверки:
`Ctrl+Shift+P` → `Tasks: Run Task` →
`AIHEROES: Check Russian base UI (read-only)`.
Задача вызывает `python -B Tools/verify_base_panel_ui.py` в
терминале VS Code и не меняет файлы.
Первый запуск через удалённый терминал: **12/12 проверок PASS**,
`STATIC_PASS_BUILD_STALE`. Одновременно существующий
`Tools/verify_one_playable_campaign.py --static-only`
показал **12/12 PASS** для маршрута основной кампании.
Это проверки исходников и подключений, не работающего игрового окна.

## Следующие обязательные проверки

1. Дождаться завершения параллельных source edits и освободить память
   штатным способом; никаких принудительных закрытий чужих процессов.
2. Собрать `AIHeroesEditor Win64 Development` с новым source manifest.
3. Выполнить `AIHeroes.UI.BasePanelCopy.*` и весь `AIHeroes`
   без ошибок и предупреждений на ТОЙ ЖЕ сборке.
4. В настоящем игровом окне открыть базу при 1280x720, 960x720,
   640x720. Проверить, не обрезаны ли самые важные цены и причины.
5. Проверить выбор, отказ, подтверждение один раз, отмену, отсутствие
   клика сквозь окно и нулевой дрейф пользовательских SaveGame SHA-256.
6. Только после этого объявлять Windows UI PASS.

Новый HUD до сборки не объявлять визуально готовым.
Сборка Unreal не запускалась в этом проходе: параллельно изменяются
другие исходники, а предыдущий manifest уже не соответствует проекту.
Ранее также наблюдался дефицит виртуальной памяти; свободный объём
на следующих замерах менялся.

## Rollback

Три новых Source-файла и новый Python-проверяющий можно убрать
только после сверки хешей и уверенности, что на них нет последующих изменений.
Из существующих `AIHeroesBasePanelHUD.cpp` и `.vscode/tasks.json`
восстанавливать только добавленные этим проходом hunks,
сохраняя чужие правки.
Никаких `git reset --hard`, `git clean`, удаления Saved,
изменения системной подкачки, commit или push не выполнялось.
