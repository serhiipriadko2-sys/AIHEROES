# AIHEROES — M4: единая карта и понятный интерфейс

**Дата:** 2026-10-30. **Состояние:** PASS для source-pinned Unreal и scripted GPU QA. **Не** ручная UX-приёмка, не релиз.

## Изменения
- Для 640×720 и 960×720 появилась компактная сводка **двух отрядов** с фактическими количеством бойцов и HP. Она не перекрывает основное действие, не раскрывает скрытые объекты и поглощает клики, чтобы не отправить случайный приказ на карте. При 1280×720 сохранена широкая карточка героя.
- В существующем досье добавлен `FAIHeroesAdvisorDossierRules::WrapMeasured`: `GetTextSize` измеряет настоящую ширину смешанного/кириллического текста; сохранены абзацы и страницы, 64 абзаца/12 000 символов, границы UTF-16 суррогатных пар, явная отметка `[REPORT LIMIT]`. Результат кешируется, а не пересчитывается каждый кадр. Старый `Wrap` сохранён.
- Локализованы **точно известные** сообщения GameMode об отсутствии живой армии и прибытии к одному из пяти известных объектов. Остаток ходов 0–4 берётся из факта; неизвестные/некорректные сообщения не преобразуются.
- `Tools/verify_live_grid_smoke.ps1` расширен опциональными width/height с сохранением прежнего значения 1280×720 по умолчанию. Теперь проверяется фактическая PNG-геометрия. Шесть прежних tracked PNG восстановлены из сделанной ранее `previous` копии; Git blob SHA исходных файлов совпал.

## Честные границы
- Технические абзацы обычного отчёта советника **по-прежнему частично английские** (например, `OBSERVED`, `PROPOSAL GATE`, `HERO STRATEGY REPORT`). Для перевода необходима отдельная проверка смысла, не автозамена непредсказуемых диагностик.
- Проверены реальная отрисовка и scripted actions, но не **ручная** удобочитаемость, системный DPI, screenshot pixel-diff с эталоном, полный Windows packaged/Android или LLM.
- UI написан через Canvas. UMG DPI Scaling из внешней документации нельзя автоматически считать применённым к этому интерфейсу.
- В этом проходе **не выполнялись Git commit, push, release или deployment**; чужие параллельные изменения сохранены без принудительного отката. В Git остаются локальные изменения и новые доказательства.
