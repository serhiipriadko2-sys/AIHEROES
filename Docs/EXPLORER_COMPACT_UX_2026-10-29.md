# AIHEROES — понятная карта на узких экранах (Explorer Copy V1)

Дата: 29.10.2026. Режим: основная кампания, Amber March.
Статус: **SOURCE IMPLEMENTED / 3 C++ UNITS COMPILED / FULL BUILD BLOCKED BY WINDOWS VIRTUAL MEMORY**.

## Зачем сделано

На старом игровом кадре 640×720 обрезалась кнопка «Постройки [G]».
Выбор лесопилки показывал непонятное английское уведомление:
«FOREST selected. Ask H for advice; Enter to move/attack.».
Исправлены только подписи. Новые игровые правила не добавляются.

## Новые/изменённые файлы в VS Code

- Source/AIHeroes/Public/AIHeroesExplorerCopy.h — контракт подписи.
- Source/AIHeroes/Private/AIHeroesExplorerCopy.cpp — короткие кнопки
  и переводы только известных событий.
- Source/AIHeroes/Private/AIHeroesExplorerHUD.cpp — две точки подключения;
  сохранены все существующие действия и hitbox.
- Source/AIHeroes/Private/Tests/AIHeroesExplorerCopyTests.cpp —
  три автоматических теста, шесть разрешений, fail-closed для ошибок.

- Действия 400/203/1/2, координаты кнопок и условия их выполнения не менялись.
